# Forge Engine — Autonomous Software Engineering Agent

An autonomous software engineering agent platform. Connect a GitHub repo, describe an engineering task in plain English, and the system plans, implements, tests, and opens a pull request.

## Tech Stack

- **Frontend:** React, TypeScript
- **Backend:** Go, Fiber, PostgreSQL, Redis
- **Agent:** Python, FastAPI
- **Infra:** Docker, GitHub App

## Quick Start

```bash
docker-compose -f infra/docker-compose.yml up -d
